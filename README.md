# Đố Mày Tiếng Anh 😈

Game đố tiếng Anh vui: trả lời sai là bị "Thầy Khịa" chửi có tiếng, cười chọc quê, hiện meme chó mèo và thỉnh thoảng dọa giật mình.

Chơi ngay trên trình duyệt (máy tính hoặc điện thoại), không cần cài gì. Mở loa để nghe chửi.

Chế độ: Đấu nhanh, Sinh tồn, Lỗi kiểu người Việt, Từ vựng, Ngữ pháp, Nghe, Gõ đáp án, Tiếng Anh tiệm nail, Sổ lỗi sai.

Ảnh meme là ảnh sưu tầm trên mạng, dùng cho vui, không thương mại. Chủ ảnh muốn gỡ xin báo để gỡ.
